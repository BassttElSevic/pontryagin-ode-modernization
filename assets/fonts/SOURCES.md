# 插页装饰字体

`Ponomar-Regular.ttf` 原样取自 [Google Fonts 官方仓库](https://github.com/google/fonts/tree/main/ofl/ponomar)，版权归 Ponomar Project Authors。

据官方说明，Ponomar 复现了二十世纪初俄罗斯东正教会 Synodal Press 的印刷字形，现用于莫斯科牧首区出版的礼仪书籍。本项目将它用于全俄文 TikZ 艺术插页的三角形题铭。字体未经修改，随项目保存，编译无需依赖操作系统安装字体。

字体遵循 SIL Open Font License 1.1；完整版权声明与许可见同目录 `OFL-Ponomar.txt`。字体许可独立于教材项目的许可。
